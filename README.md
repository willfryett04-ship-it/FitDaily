# Fit Daily

An AI wardrobe assistant that helps people organize their clothing and choose outfits with confidence.

## Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS v4 and shadcn/ui
- Supabase for authentication, data, and clothing-image storage
- OpenAI for clothing recognition and styling recommendations

## Getting started

1. Copy `.env.example` to `.env.local`.
2. Add your Supabase project URL and publishable key.
3. Run `pnpm dev`.

The foundation deliberately contains no database tables or auth screens yet. Those are the next incremental feature slices.
